# DEVSECOPS

## What is DevSecOps?

DevSecOps means integrating security controls throughout the software
development lifecycle (SDLC) instead of treating security as a final
manual stage.\
The goal is to detect issues early, automate security checks, enforce
policies in CI/CD and continuously monitoring production.

## What DevSecOps Does in daily at work?

1.  Integrates Security into development.
2.  Perform SAST (Static Application Security Testing)
3.  Perform SCA (Software Composition Analysis)
4.  Scan secrets leakage
5.  Secure IAC
6.  Scan container images.
7.  Perform DAST (Dynamic Application Security Testing)
8.  Automates security checks in CI/CD
9.  Enforce Security Gates.
10. Monitors Applications and Infrastructure
11. Manages Vulnerabilities.
12. Implements Security as a shared Responsibility.
13. Code quality check.
14. Code smells check.
15. CI/CD scanning.

## Tools and Techs used by DevSecOps.

1.  **Secure code:** SonarQube, Checkmarx
2.  **Scan Dependencies and libraries:** OWASP, Snyk
3.  **Detect Secrets:** Gitleaks, GitGurdian
4.  **Scan IaC:** Trivy, Checkov
5.  **Test Running Application:** OWASP ZAP, Burp Suite
6.  **Automate security checks:** GitHub Action, GitLab CI/CD, Jenkins
7.  **Scan container images:** Trivy, Grype
8.  **Block insecure Deployments:** SonarQube Quality Gates, OPA (Open
    Policy Agent)
9.  **Monitoring Production security:** Falco
10. **Manage Vulnerabilities:** Snyk, DefectDojo
